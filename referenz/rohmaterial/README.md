# Rohmaterial-Sichtungen

Für Drive-Ordner, aus denen mehrere Reels entstehen: einmal sichten, hier festhalten, nie neu ansehen.

- `sichtung.md`: je Clip Inhalt, bester Moment, Ausschuss
- `tags.json`: Kapitel, Tags und bester Moment je Clip (Format `tools/analyse/tags_beispiel.json`), direkt nutzbar mit `tools/analyse/shotliste.py --tags`
- `manifest.tsv`: `<Drive-ID>\t<Name>\t<Bytes>` je Clip
