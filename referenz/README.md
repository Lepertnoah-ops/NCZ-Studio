# Referenzen

Alles, was den Stil und das Material beschreibt, aber kein Werkzeug ist. Klein halten: keine Videos hier (die bleiben im Drive).

| Ordner | Inhalt |
|---|---|
| `marke/` | Logo (PNG weiß/schwarz mit transparentem Hintergrund, gern auch SVG), Farben, Schriftname, eigener Look als `.cube` |
| `stil_leitfaden/` | Vorbild-Reels, die dem Nutzer gefallen: Drive-Link, Messwerte von `tools/analyse/referenz_analyse.py` (`referenz.md`, Zeitleiste) und `tools/analyse/reel_qc.py` (`qc.md`), ein Übersichtsbild (`tools/ansicht.py reel`) |
| `rohmaterial/` | Sichtungen von Drive-Ordnern, die öfter gebraucht werden: `sichtung.md` (Highlights je Clip), `tags.json` (Format `tools/analyse/tags_beispiel.json`), `manifest.tsv` (Drive-IDs) |
| `studio/` | `fehlerquellen.md`: typische Fehler (Drive, Video, Ton, Umgebung) und wie die Werkzeuge sie abfangen, YouTube gegenüber Instagram, Methode und Grenzen von `aktionen.py` und den Hybrid-Werkzeugen |
