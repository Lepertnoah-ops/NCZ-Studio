# Referenz-Reels

Je Referenz ein Abschnitt: Datei bzw. Drive-Link, was dem Nutzer gefällt, Messwerte.

Vermessen: `python3 tools/analyse/reel_qc.py <reel.mp4> -o referenz/stil_leitfaden/<name>` (schreibt `qc.md`, `qc_timeline.png`, `qc_shots.jpg`), Übersicht: `python3 tools/ansicht.py reel <reel.mp4>`. Die Werte, die daraus Regeln werden, in `Stil-Leitfaden.md` und `stil.json` eintragen.
