# Marke

Beim „Stil festlegen“ ausfüllen (Stil-Leitfaden, Abschnitt 1).

| | |
|---|---|
| Name / Account | … |
| Logo | Dateien hier ablegen: `logo_weiss.png`, `logo_schwarz.png` (transparent), gern `logo.svg` |
| Farben | z. B. #0C0C0C, #FFFFFF, Akzentfarbe … |
| Schrift | Name; Datei (.otf/.ttf) nach `tools/fonts/`, in einer `fx.json` als `"weight": "<Dateiname ohne Endung>"` |
| Look | Name aus `tools/vfx/looks.py` oder eigene `.cube` hier, Eintrag in `stil.json` → `look` |

Einsatz im Reel: nur in den Safe Zones (oben 10 %, unten 20 %, rechts 10 % frei). Text und Logo-Einblendungen nur, wenn der Stil es vorsieht (`stil.json` → `erlaubt`) oder der Nutzer es für ein Reel will.
